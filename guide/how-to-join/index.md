# オンラインデイサービス長老大学 <br>あなたに合った「参加のしかた」のえらび方

オンラインデイサービス長老大学は、**パソコン・タブレット・スマートフォン**のどれからでも、
**ブラウザ**でも**専用アプリ**でも参加できます。
参加方法がたくさんあるぶん、「結局どれがいいの？」と迷いやすいので、
下の**3つの質問**にそって選べるようにしました。

> 💡 むずかしく考えなくて大丈夫です。**まずは Q1 の A・B・C のどれがご希望に近いか**を選んで、
> 同じ記号の【A】【B】【C】に進んでください。

---

## ▼ Q1. 参加のしかたで、いちばんご希望に近いのはどれですか？

| 記号 | こんな方 | すすむ先 |
|----|------|------|
| **A.〈ぜんぶ自動〉** | 置いておくだけで始まってほしい。操作はしたくない・できない／おひとり暮らし／毎日設定に付き添えない | → **【A】** |
| **B.〈らくらくアプリ〉** | 簡単な操作ならできる。でも、毎回じぶんでログインする手間は減らしたい | → **【B】** |
| **C.〈じぶんでブラウザ〉** | ブラウザを開いてログイン・参加するのは、無理なく続けられる | → **【C】** |

> 🔑 **A → B → C の順に「ラク（自動）」です。** 迷ったら、A から見ていくのがおすすめです。

---

## 【A】ぜんぶ自動でおまかせしたい

**置いておくだけで自動で始まる**には、**自動で起動するアプリ**が必要です。
使う（用意できる）端末で選びます。

```
お使いの端末は？
│
├─ Androidタブレットがある ───── ◎ Android版アプリ
├─ iPad がある ──────────── ◎ iPad版アプリ
├─ Amazon Fireタブレットがある ─ ◎ Fire版アプリ
│      いずれも、曜日・時間を1回だけ設定 → あとは置くだけで自動入室。
│      アプリを閉じていても、時間になれば自動で起動します。
│      電源につないだまま・Wi-Fiにつないでおくだけ。
│
├─ これから用意する ──────── ◎ おすすめ＝タブレット（Android / iPad）の
│                              いずれか → 各専用アプリ
│                              ※買う前に事務局へご相談を（下の注意）
│
└─ Windows PC / Mac / iPhone・Androidスマホ がある
       → これらは今のところ「ぜんぶ自動」にはできません。
         全自動をご希望なら、タブレット（Android / iPad）の追加がおすすめです。
         当面は【B】か【C】の方法でご参加いただけます。
```

- 👉 **Android版アプリの使い方** … [Android版アプリ 使い方ガイド](../android-app/)
- 👉 **iPad版アプリの使い方** … [iPad版アプリ 使い方ガイド](../ipad-app/)
- 👉 **Fire版アプリの使い方** … [Fireタブレット版アプリ 使い方ガイド](../fire-app/)

> ⚠️ **タブレットを新しく買う前に、事務局までご相談ください。**
> <br>とくにAndroidタブレットは、**安い機種だとマイクの調子がよくなく、声がうまく相手に届かないことがあります**（マイクの音量を自動で調整する仕組み＝オートゲインがうまく働かないため）。失敗しないよう、機種選びをお手伝いします。
> <br>※ **Fireタブレット**は、ビデオ通話の「背景ぼかし」が使えないため、**これから買う方にはおすすめしていません**（すでにお持ちの方はFireでもご参加いただけます）。

> 📱 **「ぜんぶ自動」の端末は、原則として “参加専用機” としてお使いください。**
>
> 確実に・迷わず参加できるよう、アプリが画面に固定され（**アプリ固定**）、
> その端末は基本オンラインデイサービス長老大学の参加だけに使う形になります。
>
> - 🔓 ご家族などが、**一時的にアプリ固定を解除**して、動画を見るなど他のアプリを使うことはできます。
> - 🔒 ただし、**使い終わったら必ず元（アプリ固定・自動ではじまる状態）に戻してください。**
>   戻し忘れると、次の参加が自動ではじまらないことがあります。
> - 解除のしかた・戻しかたがご不安なときは、事務局がご案内します。お気軽にご相談ください。

## 【B】簡単な操作はできる。毎回の手間を減らしたい（専用アプリ）

ご自分の端末に**専用アプリ**があれば、毎回のログインの手間が減り、参加もかんたんになります。

```
お使いの端末は？
│
├─ Windows パソコン ──── ◎ Windows版アプリ
│      毎朝「今日参加する時間」を選ぶ → 時間になると自動で入室。
│      （アプリは開いたまま・パソコンはつけたままに）
│
├─ Androidタブレット ──── ◎ Android版アプリ（自動でも「手動参加」でもOK）
│
├─ iPad ──────────── ◎ iPad版アプリ（自動でも「手動参加」でもOK）
│
├─ Amazon Fireタブレット ─ ◎ Fire版アプリ（自動でも「手動参加」でもOK）
│
├─ Androidスマホ ─────── ○ Android版アプリ（同じアプリが使えます）
│      ※「手動参加」で使います（自動起動はおすすめしません）
│
├─ iPhone ────────── ○ iPhone版アプリ（App Storeにあります）
│      ※「手動参加」で使います（自動起動はおすすめしません）
│
└─ Mac ──────────── 専用アプリはありません → 【C】ブラウザ参加へ
```

> 📱 **スマホ（Androidスマホ・iPhone）にも、それぞれ専用アプリがあります。**
> - スマホは電話としても使うため、**「時間になると自動ではじまる（自動起動）」は使いません**。参加する時間に、**ご自分でアプリを開いて、参加ボタン（Androidは「手動参加」／iPhoneは「今すぐ授業に入る」）を1回押す**使い方になります。
> - 画面が小さく、退室ボタンを出すのに、画面を指で広げたり・ずらして動かしたりといった操作が要ることがあるので、**機械が不慣れな方にはあまり向きません**。
> - それでも、**毎回URLを開いてログインするブラウザ参加よりは、アプリのほうがかんたん**です。
> - いちばんラクに参加できるのは、やはり画面の大きい**タブレット（iPad・Androidタブレット）**です。

- 👉 **Windows版アプリの使い方** … [Windows版アプリ 使い方ガイド](../windows-app/)
- 👉 **Android版アプリの使い方（タブレット・スマホ共通）** … [Android版アプリ 使い方ガイド](../android-app/)
- 👉 **iPhone・iPad版アプリの使い方** … [iPhone・iPad版アプリ 使い方ガイド](../ipad-app/)
- 👉 **Fire版アプリの使い方** … [Fireタブレット版アプリ 使い方ガイド](../fire-app/)

## 【C】ブラウザで、じぶんで参加できる（アプリは不要）

ブラウザでログイン・参加するのが無理なくできる方は、**アプリを入れなくてOK**です。

> 🔗 **ログイン用のURL**：[https://app.noiz.fun/login](https://app.noiz.fun/login)
> <br>このページを開いて、**事務局からお渡しした ID（メールアドレス）とパスワード**でログインしてください。

```
参加のしかた
│
├─ ブラウザで上のURLを開いてログインする



端末の向き・不向き
│
├─ Windows PC / Mac / Androidタブレット / iPad … ◯ 使いやすい
│
└─ スマートフォン（iPhone / Androidスマホ）…… △ 参加はできます。
       ただし画面が小さく操作しにくいので、できれば大きい端末がおすすめです。
```

> 📱 **スマホでお使いの方へ**：同じスマホでも、**ブラウザよりも専用アプリのほうがかんたん**です。アプリがある方は【B】もご覧ください（Androidスマホ・iPhoneとも専用アプリがあります）。

---

## どの方法でも共通の大切なこと

- 🔑 参加には、**事務局よりご案内したログイン情報（メールアドレス・パスワード）**が必要です。
- ❓ どれを選べばよいか迷うときは、遠慮なく事務局までご相談ください。いっしょに決めます。
