# プライバシーポリシー(オンラインデイサービス長老大学アプリ)

合同会社さわもと(以下「当社」といいます)は、当社が提供するAndroidアプリケーション「オンラインデイサービス長老大学」(パッケージ名:jp.chouroudaigaku.onlinedayservice、以下「本アプリ」といいます)における、利用者の個人情報の取扱いについて、以下のとおりプライバシーポリシー(以下「本ポリシー」といいます)を定めます。

本ポリシーは、個人情報の保護に関する法律(個人情報保護法)、その他関連法令およびGoogle Playストアのデベロッパーポリシーに準拠するものです。

## 2. 本アプリの概要

本アプリは、当社が運営するシニア向けサービス「オンラインデイサービス長老大学」への参加を補助するためのAndroidアプリケーションです。本アプリの主な機能は、株式会社TENTOが運営するビデオ通話サービス「noiz.fun」(https://noiz.fun)をWebView技術により表示し、利用者が高齢者向けオンラインデイサービスに自動的に参加できるよう支援することです。

## 3. 当社が取得する情報

### 3.1 本アプリが収集する情報

**本アプリは、利用者の個人情報を一切収集、保存、送信いたしません。**

具体的には、以下のいずれも行いません。

- 氏名、生年月日、住所、電話番号、メールアドレス等の個人を特定する情報の収集
- 端末識別子(広告ID、IMEI等)の収集
- 位置情報の取得
- 利用状況の分析(アクセス解析、利用統計等)
- クラッシュレポートの送信
- カメラまたはマイクで取得した映像・音声データの記録、保存または当社サーバーへの送信
- 連絡先、カレンダー、写真、ファイル等の端末内データへのアクセス

本アプリには、Google Analytics、Firebase Crashlytics、AdMob等のサードパーティ製分析・広告SDKは一切組み込まれていません。

### 3.2 本アプリが端末上で利用する権限

本アプリは、その機能を実現するために、Androidオペレーティングシステムの以下の権限を利用します。これらの権限により取得される情報は、すべて利用者の端末内で処理され、当社が取得または記録することはありません。

| 権限 | 利用目的 | データの送信先 |
|------|----------|----------------|
| カメラ | noiz.fun上でのビデオ通話においてご自身の映像を相手に届けるため | noiz.fun(株式会社TENTO) |
| マイク | noiz.fun上でのビデオ通話においてご自身の音声を相手に届けるため | noiz.fun(株式会社TENTO) |
| 通知の表示 | サービス開始時刻のお知らせを利用者に通知するため | 端末内のみ |
| 正確なアラーム(SCHEDULE_EXACT_ALARM) | 決められた時刻に正確にサービス開始通知を行うため | 端末内のみ |
| フルスクリーン通知(USE_FULL_SCREEN_INTENT) | サービス開始時刻に利用者の注意を確実に引くため | 端末内のみ |
| バッテリー最適化からの除外(REQUEST_IGNORE_BATTERY_OPTIMIZATIONS) | 端末がスリープ状態でも定刻にサービスを起動できるようにするため | 端末内のみ |
| インターネット接続(INTERNET) | noiz.funへの接続のため | noiz.fun(株式会社TENTO) |
| ネットワーク状態の確認(ACCESS_NETWORK_STATE) | 通信エラー検知のため | 端末内のみ |

### 3.3 noiz.fun(WebView)を通じて取得される情報

本アプリは、WebView技術により株式会社TENTOが運営する「noiz.fun」を表示します。利用者がnoiz.fun上で入力した情報、カメラ映像、マイク音声、その他noiz.funの利用に伴い発生する通信内容は、すべて株式会社TENTOのサーバーに対して送信されます。

これらの情報の取扱いについては、株式会社TENTOのプライバシーポリシーが適用されます。

- noiz.fun運営事業者:株式会社TENTO
- 株式会社TENTOのプライバシーポリシー:[https://www-tento.studio.site/privacy-policy](https://www-tento.studio.site/privacy-policy)

本アプリのご利用にあたっては、上記の株式会社TENTOのプライバシーポリシーも併せてご確認ください。

## 4. 利用目的

本アプリは前項のとおり個人情報を収集しないため、当社における個人情報の利用目的は発生いたしません。

ただし、本ポリシーに関するお問い合わせをいただいた場合に、お問い合わせ対応のためにいただいたメールアドレスおよびお問い合わせ内容を利用することがあります。

## 5. 第三者提供

当社は、本アプリを通じて個人情報を取得しないため、第三者提供は行いません。

なお、第3項3.3に記載のとおり、利用者がnoiz.fun(WebView)上で行う通信は、株式会社TENTOのサーバーとの間で直接やり取りされます。これは当社による第三者提供ではなく、利用者ご自身と株式会社TENTOとの間の通信です。

## 6. 外国にある第三者への提供

当社は、本アプリを通じて取得した個人情報を外国にある第三者に提供することはありません。

なお、noiz.funを運営する株式会社TENTOのサーバー所在地および国境を越えた通信の取扱いについては、株式会社TENTOのプライバシーポリシーをご確認ください。

## 7. 安全管理措置

本アプリは個人情報を保存・送信する設計ではないため、当社サーバー上に利用者の個人情報を保有することはありません。

本アプリ自体のセキュリティ対策として、当社は以下を実施しています。

- HTTPS通信による暗号化(noiz.funへの接続は常時HTTPS)
- Google Playストアによる署名検証およびマルウェアスキャンを経たアプリ配布
- 本アプリのソースコードの適切な管理

## 8. 開示・訂正・利用停止等の請求

当社は本アプリを通じて個人情報を保有しないため、保有個人データの開示等の請求の対象となる情報はございません。

ただし、お問い合わせの過程で当社にご提供いただいた情報については、第1項記載のお問い合わせ先までご連絡いただければ、開示、訂正、利用停止等のご請求に対応いたします。

## 9. クッキー(Cookie)等の利用について

本アプリ自体はクッキーを使用しません。

ただし、本アプリ内のWebView機能によりnoiz.funを表示する際、noiz.funがクッキーまたは類似の技術を使用することがあります。これらのクッキーの取扱いについては、株式会社TENTOのプライバシーポリシーをご確認ください。

## 10. お子様の個人情報について

本アプリは、高齢者向けのオンラインデイサービスへの参加補助を目的としており、お子様(13歳未満)のご利用を想定しておりません。お子様の個人情報を意図的に収集することはありません。

## 11. 本ポリシーの変更

当社は、法令の改正、本アプリの機能変更、その他必要に応じて、本ポリシーを変更することがあります。重要な変更を行う場合は、本ポリシーの掲載URLにおいて、変更内容および変更日を明示します。
